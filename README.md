# Zenith Psychology Frontend

Projeto frontend independente em HTML, CSS e JavaScript puro.

## Executar

```bash
npm run dev
```

Acesse:

```text
http://localhost:5173
```

Por padrao, o frontend chama a API em:

```text
http://localhost:8080
```

Para alterar a URL localmente pelo navegador:

```js
localStorage.setItem("zenithApiUrl", "http://localhost:8080");
```
